# c28studios

**C28 — Software & Cloud Engineering**  
*"We build digital products and help teams deploy, secure, and operate them reliably."*

---

## Service Hierarchy

1. **Primary — DevOps & Cloud Engineering**: Application deployment, Linux server configuration, CI/CD pipelines (GitHub Actions), Docker containerization, cloud infrastructure setup, Nginx/HTTPS, and operational monitoring.
2. **Secondary — DevSecOps Integration**: Dependency vulnerability scanning, secret management, container image scanning, and automated CI/CD security checks.
3. **Supporting — Software Development**: SaaS applications, REST/GraphQL APIs, backend systems, business web applications, and custom internal dashboards.
4. **Supporting — Website Development**: High-conversion business websites, landing pages, e-commerce, redesigns, performance optimization, and technical SEO.

---

## Tech Stack

- **Backend**: Laravel 11 (PHP 8.2+)
- **Database**: MySQL 8.0+ (`c28studios`) / SQLite in-memory for automated tests
- **Admin CMS / Control Plane**: FilamentPHP v3 (`/admin`) + Filament Builder / NioBuilder dynamic block pipeline
- **Frontend**: Laravel Blade + Alpine.js + Vanilla JS + Tailwind CSS v3.4 (via Vite)

See [`AGENTS.md`](./AGENTS.md) for the full project constitution and engineering workflow rules.
