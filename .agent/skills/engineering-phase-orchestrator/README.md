# Engineering Phase Orchestrator

Reusable, project-agnostic agent skill for controlled software engineering work.

Contents:
- `SKILL.md` — operating instructions.
- `references/phase-checklist.md` — phase checklist.
- `templates/` — design, implementation, and acceptance templates.

Install by copying this complete folder into the skills directory supported by your coding agent/IDE. Keep `SKILL.md` at the skill root. Refresh/restart the agent if required. Exact installation paths and discovery behavior vary by IDE; consult its current documentation.

The skill intentionally contains no project-specific framework, company identity, role names, colors, paths, or branch conventions.
